# at-sim

Симулятор тюнинга Hyundai/Kia. Каталоги разделены на две библиотеки:

- `@at-sim/vehicles` — существующие авто (Kia + Hyundai) и их стоковые узлы
- `@at-sim/parts` — движки, коробки, дифференциалы/AWD и правила свапа
- `@at-sim/web` — локальный интерактивный веб-интерфейс (React 19 + Vite, 100% in-memory / client-side)

## Запуск

Приложение работает полностью локально, внешний сервер и база данных не требуются:

```bash
npm install
npm test
npm run demo
npm run demo -w @at-sim/vehicles -- kia-stinger-ck-20t

# Запуск локального веб-симулятора
npm run dev
# или сборка статического бандла
npm run build
```

## Свапы

`vehicleSwaps(car)` возвращает, что встаёт:

- `bolt-in` — те же подушки / колокол / компоновка
- `kit` — известный H/K свап или адаптер
- `custom` — другая ориентация мотора, кустарщина
